# ShadowCap

A screen recording and capture application for Android, developed by SABIR7718.

## Features

- Screen recording with accessibility service integration
- Recording management and storage
- Shortcut and configuration options
- Material Design UI

## Development

This is an Android project using Kotlin and Gradle.

### Requirements
- Android Studio or compatible IDE
- Android SDK 34
- Kotlin 1.9.22
