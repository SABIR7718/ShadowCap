# ShadowCap

A screen recording and capture application for Android, developed by SABIR7718.

## License

This project is licensed under the MIT License - see the [LICENSE](LICENSE) file for details.

## Features

- Screen recording with accessibility service integration
- Recording management and storage
- Shortcut and configuration options
- Material Design UI
- Secret recording via volume button shortcut

## Releases

Latest APK: [v1.0.0](https://github.com/SABIR7718/ShadowCap/releases/tag/v1.0.0)

## Development

This is an Android project using Kotlin and Gradle.

### Requirements
- Android Studio or compatible IDE
- Android SDK 34
- Kotlin 1.9.22
